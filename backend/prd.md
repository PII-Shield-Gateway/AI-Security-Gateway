# 📌 Overview

## 프로젝트 소개

AI API(LLM, 번역 API, 챗봇 등)를 사용할 때 사용자 입력에 포함된 개인정보가 그대로 외부 서버로 전달되는 문제가 존재한다.

본 프로젝트는 외부 API 호출 이전 단계에서 개인정보를 자동으로 탐지하고 마스킹하여, 민감한 데이터가 외부로 유출되는 것을 방지하는 AI 보안 게이트웨이 시스템이다.

---

# 🚨 Problem

현재 대부분의 개발자는 별도의 보안 처리 없이 외부 AI API를 호출하고 있다.

이 과정에서 다음과 같은 위험이 발생할 수 있다.

* 이름, 전화번호, 이메일 등 개인정보 유출
* 외부 서버 저장 및 재학습 가능성
* 개인정보보호법 및 GDPR 규제 위반 가능성

즉, API 호출 자체가 보안 취약점이 될 수 있다.

---

# 🎯 Goal

* 외부 API 호출 전 개인정보 자동 탐지
* 개인정보 마스킹 및 비식별화
* 안전한 데이터 전달 구조 제공
* 개발 흐름을 방해하지 않는 경량 보안 레이어 구현

---

# 🧩 Core Features

## 1. 개인정보 탐지 (PII Detection)

사용자 입력 텍스트에서 개인정보를 자동으로 탐지한다.

### 탐지 대상

* 이름
* 전화번호
* 이메일
* 주소
* 주민등록번호
* 카드번호

---

## 2. 하이브리드 탐지 방식

### ✔ NER 기반 탐지

* 이름
* 조직명
* 문맥 기반 개인정보 인식

### ✔ Regex 기반 탐지

* 전화번호
* 이메일
* 주민등록번호
* 카드번호

두 방식을 결합하여 탐지 정확도를 향상시킨다.

---

## 3. 개인정보 마스킹

탐지된 개인정보를 안전한 토큰으로 치환한다.

| 개인정보   | 마스킹 결과      |
| ------ | ----------- |
| 이름     | `[NAME]`    |
| 전화번호   | `[PHONE]`   |
| 이메일    | `[EMAIL]`   |
| 주소     | `[ADDRESS]` |
| 주민등록번호 | `[RRN]`     |
| 카드번호   | `[CARD]`    |

---

## 4. 위험도 분석

탐지된 개인정보 조합에 따라 위험도를 계산한다.

| 조건         | 위험도    |
| ---------- | ------ |
| 개인정보 없음    | NONE   |
| 이름만 포함     | LOW    |
| 이메일만 포함    | MEDIUM |
| 전화번호만 포함   | MEDIUM |
| 이름 + 전화번호  | HIGH   |
| 이름 + 이메일   | HIGH   |
| 전화번호 + 이메일 | HIGH   |
| 3개 이상 포함   | HIGH   |

---

## 5. 외부 API 연동

마스킹된 데이터만 외부 API로 전달한다.

### 처리 흐름

```text
원본 텍스트 입력
↓
PII 탐지
↓
마스킹 처리
↓
마스킹된 데이터만 외부 API 전송
↓
API 응답 반환
```

---

## 6. 로그 기록

탐지 결과와 위험도 및 처리 여부를 저장한다.

### 로그 예시

```json
{
  "timestamp": "2026-05-06 14:30:00",
  "detected_pii": ["NAME", "PHONE"],
  "risk_level": "HIGH",
  "masked": true
}
```

# 🔄 User Flow

```text
1. 사용자 입력
2. Gateway API 요청
3. 개인정보 탐지
4. 개인정보 마스킹
5. 외부 API 호출
6. 결과 반환
```
